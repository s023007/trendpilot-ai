How we review

A recommendation must remain useful when commission is removed from the decision.

1. Start with a buyer question

Each page begins with a decision a real buyer faces, not with an advertiser feed. The page has one primary search intent and a clear use case.

2. Separate evidence types

Official product and policy pages establish current claims and terms. Independent editorial sources provide comparison context. Live product feeds provide exact offers. A research-based page does not make a hands-on performance claim.

3. Define the deciding factors

Factors can include compatibility, workflow, delivered cost, support, warranty, return economics, renewal terms, credits, MOQ, supplier capability and risk.

4. State who should not buy

A useful recommendation explains limitations and mismatched users. We do not treat every option as suitable for everyone.

5. Keep revenue outside editorial order

affiliate eligibility can be measured after the recommendation is written. Commission value does not raise an option's editorial position.

6. Apply the exact-destination rule

Affiliate commerce links should lead to a specific product or official plan page. Generic home pages can be used only when the page is about the service itself and no more precise approved link is available.

7. Update or remove

Pages carry an update date. Material plan, policy, compatibility or link changes should trigger review. A page can be removed from the sitemap when its evidence or route is no longer reliable.
