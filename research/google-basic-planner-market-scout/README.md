# Google Basic Planner Market Scout

Read-only research for TrendPilot affiliate product selection before any ad spend.

Markets: Ireland, Poland, Bulgaria, Romania, Canada.

Sellers/families: Harfington exact-part/dimension long tails and Diecast collector models.

The workflow does not create campaigns, ads, budgets, or keywords. It only calls Google Ads Keyword Planner historical metrics using the account's existing Basic Access credentials and prints market/family results to the Actions log.

Decision rule: only market/product pairs with real search demand, low-to-moderate competition, sustainable CPC, verified shipping and acceptable affiliate economics advance to paid testing.
