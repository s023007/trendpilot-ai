# TrendPilot AI v0.1

A static, mobile-responsive landing website for an AI tools and affiliate-opportunity platform.

## Upload to GitHub

1. Create a new public repository.
2. Upload **all files and folders** from this package.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will publish the site.

## Important before launch

- Replace `hello@example.com` in `index.html`, `privacy.html` and `terms.html`.
- Replace the demo tools inside `js/app.js` with real tools.
- Verify every affiliate programme and its current terms.
- Replace all demo buttons with your verified URLs.
- Connect the newsletter form to Formspree, MailerLite, Brevo or your own backend.
- Review the privacy policy and terms for your business and jurisdiction.

## Structure

- `index.html` — main website
- `privacy.html` — editable starter privacy policy
- `terms.html` — editable starter terms
- `css/style.css` — complete responsive design
- `js/app.js` — filters, search, cards and interactions
- `images/` — logo, favicon and social preview

No build tools or installation are required.
