How we test

The testing standards TrendPilot uses before making hands-on performance claims.

Research-based versus hands-on

Many early pages are research-based. They say so clearly. We do not convert catalogue specifications or third-party opinions into a false claim that TrendPilot tested the product.

Minimum hands-on record

A test record includes the product version, device or environment, test date, repeatable tasks, raw observations, failures, screenshots or photographs, and any relevant comparison baseline.

Software test

For video software we use the same representative project, measure setup and edit time, check export rules, note resource use and record which premium or credit restrictions appear.

Hardware test

For adapters and devices we test setup, repeated cold starts, stability, latency, heat, firmware path, support and return handling where practical.

Updates

If a software version, product revision or policy changes materially, the earlier result is labelled and the page is scheduled for re-test.
