TrendPilot AI v0.6.0 — Commerce-First Multi-Network Engine

PURPOSE
This release is not tied to AliExpress. Every enabled source is converted into
one offer schema, then the same discovery and matching engines work across
Admitad, CJ Affiliate, direct programmes, CSV/XML suppliers and future networks.

AFTER UPLOAD
1. Run Actions → Update trends and affiliate products.
2. Open data/source-ingestion-report.json.
3. Open data/offer-catalog-summary.json.
4. Open data/commerce-discovery-report.json.
5. Open data/trend-review.json.
6. Do not approve a trend unless readyForApproval is true.

ADDING CJ OR ANOTHER PRIVATE FEED LATER
1. Copy config/sources/_template-cj-csv.json.
2. Rename it, for example config/sources/cj-example-store.json.
3. Change id, advertiser, programme and fieldMap.
4. Change enabled to true.
5. Add one GitHub Actions secret named AFFILIATE_SOURCE_URLS_JSON.

Example secret value:
{"cj-example-store":"PRIVATE_CJ_FEED_URL","another-source":"PRIVATE_FEED_URL"}

The private URLs are read during Actions and are never written to the repository.

ADDING A LOCAL CSV/XML SUPPLIER
- Copy a generic template.
- Set location.type to local_file.
- Set location.path to the uploaded file.
- Enable the source.
- No change to the main engine is required.

SECURITY
The full normalised offer cache is created at automation/cache/offers.jsonl.
It is ignored by Git and is not committed publicly.
